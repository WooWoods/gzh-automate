# 各平台内容策略与标题公式

## 一、爆款标题四大公式

### 1.1 数字+痛点型

**公式**：`[数字] + [痛点/收益] + [解决方案暗示]`

| 示例 | 拆解 |
|------|------|
| "这5个AI工具让我每天省2小时" | 5个(数字) + 每天省2小时(收益) |
| "3步搞定PPT排版，告别加班" | 3步(数字) + 告别加班(痛点) |
| "月薪5k到3w，我只做了这4件事" | 4件事(数字) + 月薪5k到3w(收益) |
| "90%的人都不知道的7个Excel技巧" | 7个(数字) + 90%不知道(好奇心) |

**适用场景**：干货教程、工具推荐、效率提升类内容

### 1.2 悬念提问型

**公式**：`[反常识/意外事实] + ？` 或 `[现象] + 为什么/怎么办]`

| 示例 | 拆解 |
|------|------|
| "为什么越努力越穷？真相扎心了" | 反常识现象 + 好奇驱动 |
| "ChatGPT要被淘汰了？新模型已经来了" | 意外事实 + 紧迫感 |
| "同样的内容，为什么别人10w+你只有100？" | 痛点现象 + 对比落差 |
| "2025年最值得学的3个技能，你猜是啥" | 悬念 + 互动引导 |

**适用场景**：观点输出、行业分析、趋势预测类内容

### 1.3 反常识型

**公式**：`[颠覆认知的结论] + [证据暗示]`

| 示例 | 拆解 |
|------|------|
| "别再早起跑步了，研究说这时间运动最有效" | 反常识 + 研究背书 |
| "存钱是最差的理财方式" | 颠覆认知 + 引发争议 |
| "我劝你千万别学Python" | 反向建议 + 好奇心 |
| "月薪过万的人，都不在北上广" | 反常识数据 + 身份认同 |

**适用场景**：观点碰撞、科普辟谣、经验分享类内容

### 1.4 对比型

**公式**：`[A vs B] + [结论/选择建议]`

| 示例 | 拆解 |
|------|------|
| "ChatGPT vs Claude，实测50个场景后我选了..." | 对比 + 实测背书 |
| "小红书 vs 抖音，哪个更适合新手起号？" | 平台对比 + 新手痛点 |
| "iPhone 16 vs 华为Mate 70，买前必看" | 产品对比 + 购买决策 |
| "体制内 vs 自由职业，3年后的真实差距" | 职业对比 + 时间维度 |

**适用场景**：产品测评、平台对比、职业选择类内容

## 二、各平台内容策略

### 2.1 小红书

| 维度 | 策略 |
|------|------|
| **标题特征** | 18字以内，emoji点缀，口语化，强调"亲测""真实" |
| **封面风格** | 大字报/对比图/清单截图，色彩鲜明 |
| **内容结构** | 痛点引入 → 解决方案 → 效果展示 → 行动号召 |
| **最佳长度** | 300-800字（图文），30s-3min（视频） |
| **发布时机** | 12:00-13:00、18:00-20:00、21:00-23:00 |
| **爆款标签** | #亲测有效 #干货分享 #省钱攻略 #必看 |
| **互动技巧** | 结尾提问引导评论，如"你们觉得呢？评论区聊聊" |

### 2.2 抖音

| 维度 | 策略 |
|------|------|
| **标题特征** | 前3秒决定完播率，制造悬念或冲突 |
| **内容结构** | 黄金3秒钩子 → 核心内容 → 反转/升华 → 引导互动 |
| **最佳长度** | 15s-60s（短视频），3-10min（中长视频） |
| **发布时机** | 7:00-9:00、12:00-13:00、19:00-22:00 |
| **爆款特征** | 节奏快、信息密度高、有反转、有金句 |
| **互动技巧** | 评论区置顶争议观点，引发讨论 |

### 2.3 微信公众号

| 维度 | 策略 |
|------|------|
| **标题特征** | 22字以内，信息量充足，制造信息差 |
| **内容结构** | 痛点/热点引入 → 深度分析 → 案例/数据 → 结论+行动建议 |
| **最佳长度** | 1500-3000字 |
| **发布时机** | 7:00-8:00（早通勤）、12:00-13:00（午休）、21:00-22:00（睡前） |
| **爆款特征** | 有独到观点、有数据支撑、有实操价值 |
| **互动技巧** | 文末引导"分享到朋友圈"，设置投票/留言话题 |

### 2.4 B站

| 维度 | 策略 |
|------|------|
| **标题特征** | 20字以内，信息明确，可加入系列编号 |
| **内容结构** | 开场高能 → 循序渐进 → 高潮/干货 → 结尾引导三连 |
| **最佳长度** | 5-15min |
| **发布时机** | 17:00-19:00（放学/下班）、20:00-23:00 |
| **爆款特征** | 有干货、有态度、有梗、有个人风格 |
| **互动技巧** | 弹幕互动设计（"看到这里的扣1"），评论区置顶讨论话题 |

### 2.5 知乎

| 维度 | 策略 |
|------|------|
| **标题特征** | 问题导向，精准匹配搜索关键词 |
| **内容结构** | 先说结论 → 分点论证 → 案例/数据 → 总结 |
| **最佳长度** | 1000-5000字 |
| **发布时机** | 工作日 10:00-12:00、14:00-17:00 |
| **爆款特征** | 专业深度、逻辑清晰、有独特视角、有数据/图表 |
| **互动技巧** | 回答热门问题蹭流量，引用权威来源增加可信度 |

### 2.6 今日头条

| 维度 | 策略 |
|------|------|
| **标题特征** | 30字以内，信息量大，可适当夸张 |
| **内容结构** | 新闻/事件引入 → 多角度分析 → 观点输出 |
| **最佳长度** | 800-2000字 |
| **发布时机** | 6:00-8:00、11:00-13:00、17:00-19:00 |
| **爆款特征** | 时效性强、观点鲜明、接地气 |
| **互动技巧** | 标题制造讨论空间，引导用户评论站队 |

## 三、内容结构化大纲模板

### 3.1 干货教程型

```markdown
## 开头（钩子）
- 痛点场景描述（让读者"这就是我！"）
- 承诺解决方案（"看完这篇，你也能..."）

## 核心内容
### 方法/工具 1
- 是什么（一句话介绍）
- 为什么有效（原理/数据）
- 怎么用（步骤说明 + 截图/示例）

### 方法/工具 2
- （同上结构）

### 方法/工具 3
- （同上结构）

## 结尾（行动号召）
- 效果总结/对比
- 使用建议/注意事项
- 引导互动（"你用过哪个？评论区告诉我"）
```

### 3.2 观点输出型

```markdown
## 开头（钩子）
- 热点事件/现象引入
- 抛出反常识观点或尖锐问题

## 论证
### 论点 1：[核心观点]
- 证据/案例/数据
- 分析推理

### 论点 2：[补充观点]
- 证据/案例/数据
- 分析推理

### 反方观点回应
- "有人可能会说..."
- "但实际上..."

## 结尾
- 观点总结
- 升华/展望
- 引导讨论
```

### 3.3 对比测评型

```markdown
## 开头（钩子）
- 选择困难场景描述
- "我花了X天时间实测，终于有结论了"

## 对比维度
### 维度 1：[如 易用性]
- A 的表现
- B 的表现
- 本轮胜出

### 维度 2：[如 性价比]
- （同上结构）

### 维度 3：[如 适合人群]
- （同上结构）

## 总结
- 各维度得分汇总表
- 最终推荐（谁适合选A，谁适合选B）
- 引导互动
```

## 四、标题生成 Prompt 模板

为每个选题生成 3 个不同风格的标题时，使用以下 prompt 结构：

```
基于以下信息生成3个爆款标题：

话题：{topic}
账号赛道：{niche}
内容风格：{tone}
目标平台：{platform}
目标受众：{target_audience}

要求：
1. 标题1使用"数字+痛点型"公式
2. 标题2使用"悬念提问型"公式
3. 标题3使用"反常识型"或"对比型"公式
4. 每个标题控制在{platform_title_limit}字以内
5. 标题必须与账号赛道高度相关
6. 避免标题党，确保内容能兑现标题承诺
7. 标注每个标题使用的公式类型
```

### 各平台标题字数限制

| 平台 | 标题字数限制 |
|------|------------|
| 小红书 | 18字以内 |
| 抖音 | 30字以内 |
| 公众号 | 22字以内（展示区域） |
| B站 | 20字以内 |
| 知乎 | 无硬限制，建议25字以内 |
| 头条 | 30字以内 |
