## 模板使用说明

### 动态字段说明

| 字段 | 说明 | 数据来源 |
|------|------|---------|
| `{timestamp}` | 报告生成时间 | 系统时间 |
| `{account_name}` | 账号名称 | 配置文件 |
| `{niche}` | 赛道 | 配置文件 |
| `{topic_N}` | 话题标题 | 热点抓取 |
| `{heat_N}` | 热度值 | 热点抓取 |
| `{trend_N}` | 趋势标识 | 趋势分析 |
| `{sentiment_N}` | 情绪标识 | 情绪分析 |
| `{count_N}` | 跨平台数 | 数据聚合 |
| `{grade_N}` | 评级（S/A/B/C/D） | 评分模型 |
| `{score_N}` | 综合得分 | 评分模型 |
| `{H_N}` ~ `{I_N}` | 各维度得分 | 评分模型 |
| `{*_analysis_N}` | 各维度分析文本 | AI 生成 |
| `{title_Na}` | 推荐标题 | 标题生成 |
| `{match_N}` | 赛道匹配度 | 评分模型 |
| `{diff_N}` | 差异化空间评分 | 评分模型 |

### 条件渲染规则

| 条件 | 处理 |
|------|------|
| 配置文件无 `past_viral_content` | 跳过「五、历史对比与复盘」章节 |
| 某平台数据获取失败 | 在平台热度分布中标注"数据获取失败" |
| 无匹配赛道的话题 | 在「二、赛道相关热点筛选」中说明"未找到高匹配度话题，展示相关度最高的话题" |
| 选题数量 < 3 | 按实际数量输出，不凑数 |
| 选题数量 > `max_topics` | 仅输出评分最高的前 N 个 |

### 报告质量检查清单

- [ ] 所有表格格式正确，列对齐
- [ ] 趋势/情绪标识 emoji 使用正确
- [ ] 评分计算无错误（各维度加权之和 = 综合得分）
- [ ] 评级与分数区间匹配（S:90-100, A:80-89, B:70-79, C:60-69, D:<60）
- [ ] 标题与账号赛道相关
- [ ] 大纲结构完整（开头 + 核心内容 + 结尾）
- [ ] 创作建议具体可操作（非空泛建议）
- [ ] 报告文件名包含时间戳
