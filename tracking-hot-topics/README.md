# tracking-hot-topics

> 追踪全网热点话题，自动生成适配你账号定位的爆款选题方案

面向自媒体创作者和内容运营的 AI 选题辅助工具。实时抓取微博、抖音、小红书、知乎、百度、B站、头条、公众号等 8 大平台的热点数据，结合你的账号赛道、内容风格和粉丝画像，输出带爆款潜力评级的选题报告。

## 它能做什么

- **全平台热点监控**：一次触发，同时扫描 8 个平台的热搜热榜
- **赛道智能匹配**：根据你预设的账号定位，自动筛选高匹配度话题
- **爆款标题生成**：每个选题输出 3 个不同风格的标题（数字痛点型 / 悬念提问型 / 反常识型）
- **结构化大纲**：直接给出开头钩子、核心内容、结尾互动的完整大纲
- **六维度潜力评级**：从热度、匹配度、竞争、情绪、时效、互动六个维度量化评分，输出 S/A/B/C/D 等级
- **情绪与趋势分析**：判断话题处于萌芽期、爆发期还是衰退期，预判用户情绪倾向
- **竞品差异化**：对比竞品已覆盖的角度，帮你找到差异化切入点
- **完整 Markdown 报告**：一份可直接使用的选题报告，保存到本地随时查阅

## 快速开始

### 1. 安装

将整个 `tracking-hot-topics` 目录放入你的 SOLO Skills 目录：

```
tracking-hot-topics/
├── SKILL.md                          # Skill 主文件
├── references/                       # 参考文档
│   ├── config-schema.md              # 配置文件说明
│   ├── platform-apis.md              # 平台接口文档
│   ├── scoring-model.md              # 评分模型说明
│   ├── content-strategies.md         # 内容策略与标题公式
│   └── report-template.md            # 报告输出模板
└── scripts/                          # 辅助脚本
    ├── fetch_hot_topics.py           # 热点数据抓取
    ├── analyze_trends.py             # 趋势分析
    └── score_topics.py               # 选题评分
```

### 2. 首次使用

在对话中输入任意触发词即可启动：

```
> 帮我看看今天的热点
> 最近有什么选题推荐
> 追热点
```

首次运行时，Skill 会引导你填写账号信息（账号名、平台、赛道等），完成后自动保存配置，后续无需重复填写。

### 3. 定时执行

支持定时自动追踪，例如每天早上 9 点生成选题日报：

```
> /loop 0 9 * * * 运行热点选题追踪
```

## 工作原理

整个流程分为 6 个阶段：

```
配置加载 → 多平台抓取 → 趋势分析 → 选题匹配 → 潜力评级 → 报告生成
```

| 阶段 | 说明 |
|------|------|
| Phase 0 | 读取用户账号配置（赛道、风格、粉丝画像），首次使用时引导填写 |
| Phase 1 | 6 个并行 Agent 同时抓取 8 大平台热点数据 |
| Phase 2 | 跨平台话题聚合、热度趋势判断、用户情绪分析 |
| Phase 3 | 赛道匹配筛选、生成标题（3 选 1）、搭建内容大纲、输出创作建议 |
| Phase 4 | 六维度量化评分，输出 S/A/B/C/D 爆款潜力评级 |
| Phase 5 | 生成完整 Markdown 报告并保存到本地 |

## 六维度评分模型

每个选题从六个维度进行量化评分：

| 维度 | 权重 | 评估内容 |
|------|------|---------|
| 热度趋势 H | 25% | 搜索频率、跨平台覆盖度、热度增速 |
| 赛道匹配 M | 25% | 关键词命中、粉丝画像契合、内容风格适配 |
| 竞争差异 D | 20% | 同类内容密度、差异化角度空间、竞品覆盖度 |
| 情绪激活 E | 15% | 情绪强度、共鸣广度、争议性 |
| 时效窗口 T | 10% | 生命周期阶段、剩余红利时间 |
| 互动潜力 I | 5% | 评论讨论空间、UGC 引发可能 |

**评级标准**：

| 等级 | 分数 | 建议 |
|------|------|------|
| S | 90-100 | 立即创作，抢占第一波流量 |
| A | 80-89 | 今日内完成创作发布 |
| B | 70-79 | 纳入本周创作计划 |
| C | 60-69 | 观察热度变化，备选 |
| D | <60 | 不建议投入 |

## 配置文件

首次使用后会在工作目录生成 `hot-topics-config.yaml`，支持以下配置项：

- **账号信息**：名称、主阵地平台、赛道、细分方向、内容风格
- **粉丝画像**：年龄段、性别、兴趣标签、核心痛点
- **内容偏好**：擅长形式、平均长度、更新频率、回避话题
- **过往爆款**：历史爆款标题和数据（用于校准评分模型）
- **竞品账号**：对标竞品的优势和劣势（用于差异化分析）
- **报告设置**：输出目录、最大选题数、最低收录分数

详细字段说明见 [references/config-schema.md](references/config-schema.md)。

## 输出示例

运行后会生成一份 Markdown 报告，包含以下章节：

1. **全网热点概览** — TOP 10 话题 + 各平台热度分布
2. **赛道相关热点筛选** — 按匹配度排序的话题列表
3. **重点选题方案** — 评级、六维度评分、3 个标题、大纲、创作建议、竞品差异化
4. **情绪与趋势分析** — 情绪分布 + 走势预判
5. **历史对比与复盘** — 与过往爆款的相似度分析（需配置过往爆款数据）
